# Отчёт по лабораторной работе №4

Эмуляция и измерение задержек в глобальных сетях

1/7

# Цель и задания

Познакомиться с NETEM и научиться моделировать задержки и джиттер в виртуальной сети Mininet. Создать сеть из двух хостов и коммутатора, измерить RTT с помощью ping, изменить параметры задержки и сравнить результаты эксперимента.

2/7

# Подготовка рабочего каталога

Создаём сеть Mininet из двух хостов и коммутатора. Проверяем связь между h1 и h2 командой ping и фиксируем исходные значения RTT.

3/7

![Подготовка рабочего каталога](netem_presentation_imgs/slide-03.png)

# Создание топологии через API Mininet

На интерфейсе h1 задаём задержку 100 мс. Затем добавляем 100 мс на h2, чтобы получить двунаправленную задержку. После измерений меняем задержку на обоих интерфейсах до 50 мс.

4/7

![Создание топологии через API Mininet](netem_presentation_imgs/slide-04.png)

# Проверка топологии

Для моделирования нестабильной сети задаём среднюю задержку 100 мс со случайным отклонением 10 мс. Дополнительно проверяем вариант с корреляцией 25%.

5/7

![Проверка топологии](netem_presentation_imgs/slide-05.png)

# Параметры хостов

Задаём нормальное распределение задержки со средним значением 100 мс и отклонением 20 мс. С помощью ping проверяем, как меняются значения RTT.

6/7

![Параметры хостов](netem_presentation_imgs/slide-06.png)

# Вывод

В ходе лабораторной работы была создана виртуальная сеть Mininet и проверено соединение между двумя хостами. С помощью NETEM исследовано влияние фиксированной задержки, джиттера, корреляции и распределения задержки на время передачи пакетов. Также рассмотрена возможность автоматизации эксперимента и построения графика по результатам ping.

7/7
