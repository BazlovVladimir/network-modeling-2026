## Цель работы

Основной целью работы является знакомство с инструментом для измерения пропускной способности сети в режиме реального времени — iPerf3, а также получение навыков проведения воспроизводимого эксперимента по измерению пропускной способности моделируемой сети в среде Mininet.

## Задание

1. Воспроизвести посредством API Mininet эксперименты по измерению пропускной способности с помощью iPerf3.
2. Построить графики по проведённому эксперименту.

## Выполнение работы

### 3.1. Подготовка окружения и проекта

#### 3.1.1. Подготовка рабочего каталога

Для выполнения работы используется каталог `~/work/lab_iperf3`. В нём создан подкаталог `lab_iperf3_topo`, после чего файл `mininet/examples/emptynet.py` скопирован в рабочий каталог и переименован в `lab_iperf3_topo.py`.

**Место для скриншота:** подготовка рабочего каталога и копирование `emptynet.py`.

#### 3.1.2. Создание топологии через API Mininet

Сценарий `lab_iperf3_topo.py` создаёт сеть с контроллером `c0`, двумя хостами `h1` и `h2` и коммутатором `s3`. Хостам назначаются IP-адреса `10.0.0.1` и `10.0.0.2`. Между каждым хостом и коммутатором создаётся двунаправленная связь.

**Основные строки создания топологии:**

```python
net = Mininet()

c0 = net.addController('c0')
h1 = net.addHost('h1', ip='10.0.0.1')
h2 = net.addHost('h2', ip='10.0.0.2')
s3 = net.addSwitch('s3')

net.addLink(h1, s3)
net.addLink(h2, s3)

net.start()
```

**Место для скриншота:** листинг `lab_iperf3_topo.py`.

#### 3.1.3. Проверка топологии

После запуска скрипта выполнена проверка элементов топологии средствами CLI Mininet с помощью команд `net`, `links` и `dump`. После проверки работа Mininet завершена командой `exit`.

**Место для скриншота:** результат выполнения `net`, `links` и `dump`.

### 3.2. Вывод параметров хостов

#### 3.2.1. Информация о хосте h1

После запуска сети в сценарий добавлена команда вывода имени, IP-адреса и MAC-адреса хоста `h1`. Для этого используются `h1.name`, `h1.IP()` и `h1.MAC()`.

**Место для скриншота:** вывод параметров хоста `h1`.

#### 3.2.2. Информация об обоих хостах

Затем аналогичный вывод реализован для `h1` и `h2`. Корректность изменения проверяется повторным запуском сценария.

**Место для скриншота:** вывод параметров обоих хостов.

### 3.3. Ограничение производительности

#### 3.3.1. CPULimitedHost и TCLink

Создана копия сценария `lab_iperf3_topo2.py`. В начало файла добавлены импорты `CPULimitedHost` и `TCLink`. Объект `Mininet` настроен на использование `CPULimitedHost` в качестве класса хоста и `TCLink` в качестве класса канала.

```python
from mininet.node import CPULimitedHost
from mininet.link import TCLink

net = Mininet(
    host=CPULimitedHost,
    link=TCLink
)
```

**Место для скриншота:** листинг с импортом `CPULimitedHost` и `TCLink`.

#### 3.3.2. Настройка h1 и h2

Для `h1` задано выделение 50% общих ресурсов процессора, для `h2` — 45%.

```python
h1 = net.addHost('h1', ip='10.0.0.1', cpu=0.5)
h2 = net.addHost('h2', ip='10.0.0.2', cpu=0.45)
```

**Место для скриншота:** настройки CPU для `h1` и `h2`.

#### 3.3.3. Настройка сетевого канала

Соединение `h1` с коммутатором настроено с пропускной способностью 10 Мбит/с, задержкой 5 мс, максимальным размером очереди 1000 пакетов и потерями 10%. Используется ограничитель HTB.

```python
net.addLink(
    h1,
    s3,
    bw=10,
    delay='5ms',
    max_queue_size=1000,
    loss=10,
    use_htb=True
)
```

**Место для скриншота:** настройка `TCLink` и параметры канала.

### 3.4. Воспроизводимый эксперимент iPerf3

#### 3.4.1. Подготовка lab_iperf3.py

На основе `lab_iperf3_topo2.py` создан сценарий `lab_iperf3.py`. В него добавлен модуль `time`. Согласно заданию, в итоговом сценарии на хостах отсутствует ограничение использования ресурсов CPU, а каналы настроены на 100 Мбит/с с задержкой 75 мс, без потерь, без ограничителя пропускной способности и без ограничения максимального размера очереди.

**Место для скриншота:** листинг `lab_iperf3.py` с настройками топологии.

#### 3.4.2. Запуск сервера и клиента

После запуска сети на хосте `h2` запускается сервер iPerf3. Через 10 секунд на `h1` запускается клиент iPerf3. CLI-интерфейс Mininet в данном сценарии закомментирован.

```python
h2.cmdPrint('iperf3 -s -D -1')
time.sleep(10)
h1.cmdPrint('iperf3 -c', h2.IP(), '-J > iperf_result.json')
```

**Место для скриншота:** команды запуска сервера и клиента iPerf3.

#### 3.4.3. Экспорт результатов в JSON

Ключ `-s` запускает iPerf3 в режиме сервера, `-D` переводит сервер в фоновый режим, а `-1` ограничивает сервер одним клиентом. В клиентском вызове ключ `-c` задаёт адрес сервера, ключ `-J` включает JSON-формат вывода, а перенаправление `>` сохраняет результат в `iperf_result.json`.

**Место для скриншота:** результат запуска `sudo python lab_iperf3.py`.

**Место для скриншота:** проверка созданного `iperf_result.json`.

### 3.5. Построение графиков

#### 3.5.1. Обработка JSON-файла

После завершения эксперимента графики строятся из полученного JSON-файла командой:

```bash
plot_iperf.sh iperf_result.json
```

**Место для скриншота:** запуск построения графиков.

#### 3.5.2. Результаты визуализации

На основании результатов iPerf3 формируются графики, отображающие параметры сетевого эксперимента.

**Место для графика:** пропускная способность (Throughput).

**Место для графика:** количество повторных передач (Retransmits).

**Место для графика:** RTT.

**Место для графика:** вариация RTT (RTT Var).

**Место для графика:** размер окна перегрузки TCP (cwnd).

**Место для графика:** объём переданных данных (Transferred Data).

### 3.6. Автоматизация с помощью Makefile

#### 3.6.1. Создание Makefile

Для автоматизации последовательности действий создан `Makefile`, включающий запуск эксперимента, построение графиков и очистку результатов.

```makefile
all: iperf_result.json plot

iperf_result.json:
	sudo python lab_iperf3.py

plot: iperf_result.json
	plot_iperf.sh iperf_result.json

clean:
	-rm -f *.json *.csv
	-rm -rf results
```

#### 3.6.2. Проверка make clean и make

Проверяется корректность автоматизации с помощью команд:

```bash
make clean
make
```

В результате `make` запускает эксперимент, сохраняет результаты iPerf3 в JSON и выполняет построение графиков.

**Место для скриншота:** выполнение `make clean` и `make`.

### 3.7. Завершение работы

После выполнения всех экспериментов соединение с виртуальной машиной Mininet завершается, виртуальная машина выключается.
